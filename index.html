Google Calendar

Conecta el calendario de este auditor para ver en el panel «Calendario» los eventos que cree como auditorías. La app solo lee los eventos; no los modifica.

«primary» es el calendario principal de la cuenta. Para otro calendario usa su ID (Configuración del calendario → Integrar calendario).
Si la escribes, solo se muestran eventos cuyo título o descripción la contengan. Vacío = todos los eventos.
Cómo activar la conexión (una sola vez)
  1. Entra a console.cloud.google.com y crea un proyecto (por ejemplo «Auditor SG-SST»).
  2. En APIs y servicios → Biblioteca, habilita Google Calendar API.
  3. En Pantalla de consentimiento de OAuth (Google Auth Platform): elige Externo (o Interno si todos usan el mismo Google Workspace). Agrega el alcance https://www.googleapis.com/auth/calendar.events.readonly. Mientras esté en modo «Prueba», agrega el correo de cada auditor como usuario de prueba.
  4. En Credenciales → Crear credenciales → ID de cliente de OAuth → Aplicación web, en Orígenes autorizados de JavaScript agrega la dirección https exacta desde donde abres esta app: . No necesitas URI de redireccionamiento.
  5. Copia el ID de cliente y pégalo arriba. Luego presiona Conectar con Google y acepta el permiso de solo lectura.

Google no permite iniciar sesión desde un archivo abierto directamente del equipo (file://); la app debe abrirse desde una dirección https (o localhost). El acceso dura aproximadamente una hora; después aparecerá «Reconectar».
